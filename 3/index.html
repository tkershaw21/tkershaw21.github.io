Solar System Explorer

CSCI 3054 Web Programming - Project 2

Tyrell Kershaw

Topic Description

The Solar System is the collection of the Sun and the planets, moons, dwarf planets, asteroids, comets, and other objects that orbit it. Although people learn about the Solar System in school, there is a large amount of information about these objects that can be difficult to organize and explore. My web application, Solar System Explorer, will provide users with an organized and interactive way to learn about different objects in the Solar System. I chose this topic because space and astronomy provide many interesting subjects to explore, and a web application can make the information easier to navigate than searching through many different websites.

There are already websites that provide information about space. For example, NASA provides extensive information about planets, moons, spacecraft, missions, and other areas of space science. The European Space Agency also provides educational information about astronomy and space missions. However, these resources contain a large amount of information across many different pages. Solar System Explorer will focus specifically on organizing information into a simple two-step exploration process. Users will first select a category of Solar System object and then select a specific object from that category. This approach will give users a simple way to find information without having to search through unrelated information.

Application Description

The first page of the application will be the Home page. This page will introduce users to the Solar System Explorer and explain what they can learn from the application. It will contain a short introduction to the Solar System, space-related images, and navigation links to the other pages. The goal of the Home page will be to give users an understanding of what the application does before they begin exploring the available objects.

The second page will be the Explore page. This will be the main interactive portion of the application. Users will complete two steps in sequence. First, they will select one of four categories of Solar System objects. After making that selection, the application will provide four choices from that category. The user will then select one of those objects to see information about it. The final result will contain the object's name, image, description, size, location or distance, and an interesting fact.

Two-Step Interaction

  1. Step 1: Choose a category
    • Planets
    • Moons
    • Dwarf Planets
    • Small Solar System Bodies
  2. Step 2: Choose an object from the selected category
    • Planets: Mercury, Venus, Earth, Mars
    • Moons: Moon, Europa, Titan, Ganymede
    • Dwarf Planets: Pluto, Ceres, Eris, Haumea
    • Small Solar System Bodies: Asteroids, Comets, Meteoroids, Kuiper Belt Objects

This interaction creates 16 possible final choices. The second choice will depend on the first choice, so users will not be able to select an object until they have selected its category. Once an object is selected, the application will display the same types of information for every selection. This information will include the object's name, an image, a short description, its size, its location or distance, and an interesting fact. The data can eventually be stored in a JSON file and later transferred into the database used by the application.

Additional Application Data

The third page of the application will contain general Solar System information that users can read without making a selection. This information will not repeat the object-specific information from the Explore page. Possible topics will include how the Solar System formed, how gravity affects objects, how planets orbit the Sun, the difference between planets and dwarf planets, and the history of space exploration. The page may also include information about spacecraft and important discoveries that have helped scientists understand our Solar System.

Contact Us

The fourth page will be a Contact Us page. This page will initially be static, but it can later be connected to the application's database. The application will eventually collect the user's name, email address, subject, and message. Users could use the form to provide feedback about the application, report incorrect information, or suggest additional objects that could be included in the Solar System Explorer.
